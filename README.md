# EduLearn - Educational Platform Website

## Project Overview
EduLearn is a comprehensive, multi-page educational platform website built using HTML, CSS, and JavaScript. It serves as a complete college submission project demonstrating advanced web development concepts and best practices.

## Pages Included
1. **Home** (`index.html`) - Hero section, features, popular courses, testimonials, CTA
2. **About** (`about.html`) - About us, mission, vision, team members
3. **Courses** (`courses.html`) - Course listing with filtering and search functionality
4. **Blog** (`blog.html`) - Blog posts with load more functionality
5. **Contact** (`contact.html`) - Contact form with validation, Google Maps embed
6. **Login/Signup** (`login.html`) - Authentication forms with tab switching

## Features Demonstrated
### HTML
- Semantic HTML5 elements (`<header>`, `<section>`, `<article>`, `<footer>`)
- Forms with validation
- Responsive meta tags
- External resources (Google Fonts, Font Awesome)

### CSS
- CSS Variables for theming
- Flexbox and Grid layouts
- Media queries for responsive design
- Animations and transitions
- Box shadows and gradients
- Custom styling for all components

### JavaScript
- DOM manipulation
- Event handling (click, submit, scroll)
- Form validation
- Dynamic content rendering
- Array filtering and searching
- LocalStorage for user authentication
- Intersection Observer for scroll animations
- Testimonial slider with auto-play
